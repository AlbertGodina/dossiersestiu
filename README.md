## 🖨️ Com imprimir

1. Obre el dossier al navegador
2. Clica el botó **"Descarregar / Imprimir PDF"**
3. Selecciona **"Desa com a PDF"** (o la impressora)
4. Format **A4**, **sense marges** (o marges mínims)

---

## 🚀 Com publicar a GitHub Pages

1. Crea un repositori públic a GitHub amb el nom `dossiers-estiu`
2. Puja tots els fitxers d'aquest projecte
3. Ves a **Settings → Pages**
4. Selecciona la branca `main` i la carpeta `/root`
5. Guarda — en uns minuts el lloc serà accessible a `https://TU_USUARI.github.io/dossiers-estiu`

---

## ✏️ Com afegir un nou bloc

1. Afegeix les noves pàgines al final del fitxer `dossiers/i5-1r/index.html`
2. Actualitza el comptador de punts a `index.html` (`.prog-dot.fet`)
3. Canvia el pill corresponent de `aviat` a `fet` al dossier
